# STHGroup Cutting — расчёт коммерческого распила

Программа для Windows (Electron). Считает работу для заказчиков по коммерческому распилу и выдаёт КП или счёт в PDF.
Название программы рабочее, оно задано в одном месте: `APP_NAME` в `main.js` (и `<title>` в `renderer/index.html`).

## Запуск

Нужен Node.js 20 или новее.

```
npm install
npm start
```

Установщик для Windows (`dist/STHGroup Cutting Setup 0.1.0.exe`) собирается на Windows командой:

```
npm run dist
```

Проверка расчётного ядра: `npm test`.

## Что умеет

- **Заказы**: номер, клиент, статус (Расчёт, В работе, Готов, Выдан, Отменён), копия заказа, поиск, сумма долга.
- **Детали**: ручной ввод таблицей, загрузка `.bmk` или CSV из Excel, шаблон CSV.
  У детали: материал, длина, ширина, количество, запрет поворота (текстура), кромка на 4 стороны,
  присадка (глухие в пласть, сквозные, в торец), фрезеровка в погонных метрах.
- **Раскрой**: упаковка деталей по листам (MaxRects) с учётом пропила, обрезки кромки листа и запрета поворота,
  карты раскроя, деловые остатки.
- **Цена**: распил по площади деталей или по площади израсходованных листов (выбирается в заказе), своя цена за м² у каждого материала,
  свой материал или кромка (продажа листов и кромки), кромление, присадка и фрезеровка четырьмя способами
  (за отверстие, за метр, за деталь на ЧПУ, по времени станка — включаются галочками в настройках),
  дополнительные позиции, скидка, минимальная сумма заказа.
- **КП и счёт в PDF** с шапкой STHGroup, перечнем деталей и картами раскроя по желанию.
- **Оплаты и долги**, файлы заказа (хранится путь), список выданных PDF.
- **Клиенты** (контакты и реквизиты), **остатки** (склад деловых остатков).
- **Смета** (раздел в меню и вкладка в заказе): база материалов по образцу Базис-Мебельщика, см. ниже.

## Где лежат данные

Откройте в программе Настройки, затем «Открыть папку с данными». Там:

- `database.json` — заказы, клиенты, остатки, настройки;
- `smeta-base.json` — база материалов («Смета»); `materials.json` — прежняя база, используется только при первом запуске;
- `backups/` — ежедневная копия базы, хранятся последние 30.

Другой файл базы материалов выбирается на вкладке «Материалы».

## Смета: база материалов

Раздел «Смета» в меню. Слева дерево групп (листовые, кромочные, погонные, фурнитура, услуги), справа материалы выбранной группы.

- **Карточка материала**: наименование, артикул, код, идентификатор для синхронизации, единица, поставщик, класс, закупочная цена,
  наценка, продажная цена, цена работы (распил за м² или кромление за м.п.), толщина и размеры листа, коэффициент избытка, текстура,
  наличие, ссылка, примечание, история цен.
- **Наценка**: процент, умножение, добавка или фиксированная цена. Задаётся на группу (наследуется вложенными группами и материалами)
  или на материал, с округлением (0 — до рублей, −1 — до десятков).
- **Добавить по ссылке**: программа читает страницу товара (название, артикул, цену, магазин). Чего не нашла, подсвечивает жёлтым.
  Если сайт не открылся, можно вставить скопированный текст или код страницы. «Обновить по ссылке» в карточке меняет цену.
- **Импорт XML и CSV**, экспорт XML и CSV, обновление цен из файла по артикулу, названию или идентификатору, поиск и удаление дубликатов.
  Теги, которых программа не знает, сохраняются в материале и уходят обратно при экспорте.
- **Смета заказа** (вкладка «Смета» в заказе): позиции из базы, заполнение из заказа (листы и кромка), обновление цен из базы,
  итоги по продаже, закупке и наценке. PDF сметы содержит только цены продажи. Галочка «Включить смету в итог заказа» добавляет позиции в КП и счёт.

База хранится в `smeta-base.json` в папке данных. При первом запуске туда переносится прежний `materials.json`.
Ежедневная копия: `backups/smeta-ГГГГ-ММ-ДД.json`, хранятся последние 30.

## Важно про импорт `.bmk`

Формат `.bmk` из BazisReborn мне недоступен, поэтому импорт читает его по догадке: ищет в JSON (или в JSON внутри архива)
список объектов с длиной и шириной и узнаёт поля по названиям (см. `ALIASES` в `core/importers.js`).
Если у вашего файла другая структура, программа скажет, что список деталей не найден: пришлите образец `.bmk`,
и импорт будет подогнан точно. До тех пор детали можно загружать через CSV или вводить вручную.

## Открытие моделей Базис-Мебельщик (.b3d)

В заказе: **«Открыть модель .b3d, .bmk или CSV…»**. Программа читает файл сама, Базис не нужен:
- детали: размеры (по контуру), количество (одинаковые детали складываются), материал, направление текстуры;
- кромка по сторонам детали (L1/L2/W1/W2);
- присадка: отверстия крепежа распределяются по деталям по координатам (глухие, сквозные, в торец);
- фрезеровка: длина траекторий пазов и четвертей, м;
- фурнитура и профили — во вкладку «Смета» заказа (вне общей суммы, пока не проверите цены).

Материалы, кромка и фурнитура, которых нет в базе, добавляются в «Смету» с нулевыми ценами — заполните их.
Отверстия, не попавшие ни в одну деталь, и кромка на скошенных/вырезных сторонах выводятся в замечаниях.

## База материалов — формат Базис-Мебельщика (0.4.0)

«Смета» → «Импорт XML/CSV…» понимает выгрузку базы Базиса (`<Database><Materials><Material>` с 37 полями): 14 тыс. позиций грузятся за доли секунды, дерево строится по `Group_Name`, `Коэф` — это наценка (продажа = цена × коэф), повторяющиеся артикулы не склеиваются. Экспорт пишет тот же XML со всеми полями. Цена за м² (кв.м) пересчитывается в цену листа по размерам. Модель .b3d подбирает материалы, кромку и фурнитуру в базе по артикулу и строит смету (площадь, кромка в м.п., фурнитура); чего нет в базе — кладётся в «08. Для разбора».

### Чтение базы Базиса напрямую (.FDB)

«Смета» → «Открыть .FDB Базиса…» читает файл `NK_BAZE.FDB` (Firebird 2.5) без Базиса и без сервера Firebird: материалы, единицы, классы, размеры и дерево групп (включая пустые). На базе 14 101 позиций чтение занимает доли секунды; цены, единицы, коэффициенты, классы и наличие совпадают с XML-выгрузкой Базиса. Файл не изменяется. Поля `IsTape` и `Sign` (обозначение) в XML Базиса считаются иначе, поэтому из FDB они могут отличаться; на расчёт это не влияет.

## Расчёт за лист, раскрой БазисReborn, цены с сайтов (0.6.0)
- **Цена за лист.** «Настройки → Расчёт: цена за лист»: распил + кромление + присадка — одна цена за лист материала. Цена берётся по порядку: у материала → у его группы (или группы выше) → по умолчанию. Норма кромки (м.п.) и отверстий на лист входит в цену, сверх нормы — доплата за м.п. и за отверстие. «Материал наш» и «Кромка наша» — отдельными строками. Если у какого-то материала заказа цены листа нет, заказ считается по площади (как раньше) с предупреждением. В заказе на вкладке «Расчёт» способ можно сменить для этого заказа.
- **Раскрой.** Гильотинный алгоритм из БазисReborn (`core/rebcut.js`, сквозные резы, ограничения станка) через переходник `core/cutter.js`. Деловые остатки — обрезки из дерева резов не меньше «Деловой остаток от».
- **Цены по ссылке под своим входом.** В карточке материала «Войти на сайт» — окно сайта, логин и пароль вводятся на самом сайте (программа их не видит; вход хранится в отдельном профиле `persist:shops`). «Обновить по ссылке» и «Обновить цены по ссылкам» (все материалы со ссылкой, по очереди с паузой) читают страницу в скрытом окне под этим входом — видны персональные цены и страницы на скриптах. Дополнительно разбираются наличие, остаток на складе, «актуально на» и характеристики (в примечание).
