# STHGroup Cutting — расчёт коммерческого распила

Программа для Windows (Electron). Считает работу для заказчиков по коммерческому распилу и выдаёт КП или счёт в PDF.
Название программы рабочее, оно задано в одном месте: `APP_NAME` в `main.js` (и `<title>` в `renderer/index.html`).

## Запуск

Нужен Node.js 20 или новее.

```
npm install
npm start
```

Установщик для Windows (`dist/STHGroup Cutting Setup 0.1.0.exe`) собирается на Windows командой:

```
npm run dist
```

Проверка расчётного ядра: `npm test`.

## Что умеет

- **Заказы**: номер, клиент, статус (Расчёт, В работе, Готов, Выдан, Отменён), копия заказа, поиск, сумма долга.
- **Детали**: ручной ввод таблицей, загрузка `.bmk` или CSV из Excel, шаблон CSV.
  У детали: материал, длина, ширина, количество, запрет поворота (текстура), кромка на 4 стороны,
  присадка (глухие в пласть, сквозные, в торец), фрезеровка в погонных метрах.
- **Раскрой**: упаковка деталей по листам (MaxRects) с учётом пропила, обрезки кромки листа и запрета поворота,
  карты раскроя, деловые остатки.
- **Цена**: распил по площади деталей или по площади израсходованных листов (выбирается в заказе), своя цена за м² у каждого материала,
  свой материал или кромка (продажа листов и кромки), кромление, присадка и фрезеровка четырьмя способами
  (за отверстие, за метр, за деталь на ЧПУ, по времени станка — включаются галочками в настройках),
  дополнительные позиции, скидка, минимальная сумма заказа.
- **КП и счёт в PDF** с шапкой STHGroup, перечнем деталей и картами раскроя по желанию.
- **Оплаты и долги**, файлы заказа (хранится путь), список выданных PDF.
- **Клиенты** (контакты и реквизиты), **остатки** (склад деловых остатков).
- **База материалов** — отдельный файл `materials.json`, который вы ведёте сами; программа его только читает.

## Где лежат данные

Откройте в программе Настройки, затем «Открыть папку с данными». Там:

- `database.json` — заказы, клиенты, остатки, настройки;
- `materials.json` — база материалов и фурнитуры (создаётся с примером при первом запуске);
- `backups/` — ежедневная копия базы, хранятся последние 30.

Другой файл базы материалов выбирается на вкладке «Материалы».

## Формат `materials.json`

```json
{
  "materials": [
    { "id": "ldsp16-white", "name": "ЛДСП 16 Белый", "thickness": 16, "sheetW": 2800, "sheetH": 2070,
      "servicePerM2": 350, "salePerSheet": 2400 }
  ],
  "edges": [
    { "id": "abs04-white", "name": "ABS 0,4 Белый", "servicePerM": 20, "salePerM": 15 }
  ],
  "hardware": [
    { "id": "confirmat", "name": "Конфирмат 7×50", "unit": "шт.", "salePrice": 3 }
  ]
}
```

`id` у материалов и кромок должен быть уникальным и не меняться: на него ссылаются детали в заказах.

## Важно про импорт `.bmk`

Формат `.bmk` из BazisReborn мне недоступен, поэтому импорт читает его по догадке: ищет в JSON (или в JSON внутри архива)
список объектов с длиной и шириной и узнаёт поля по названиям (см. `ALIASES` в `core/importers.js`).
Если у вашего файла другая структура, программа скажет, что список деталей не найден: пришлите образец `.bmk`,
и импорт будет подогнан точно. До тех пор детали можно загружать через CSV или вводить вручную.
