# STHGroup

Программа для Windows к «БАЗИС-Мебельщику» для производства STHGroup: модель в 3D, раскрой листов, смета, база материалов. С версии 0.7.0 окно программы — копия окна BazisReborn (папка `web`), без разделов «Деталировка», «Присадка», «Сборка», без отзывов, регистрации и обновлений BazisReborn.

## Устройство
- `main.js` — оболочка Electron: окно, системные окна выбора файла, PDF (печать встроенным Chromium), открыть файл/ссылку, масштаб, вход на сайты магазинов (`/api/shop/login`, `/api/shop/fetch`), обновления через GitHub Releases (electron-updater) — как раньше. Принудительная проверка — кнопка «Проверить обновления» в настройках (вкладка «Обновления»): окно зовёт `POST /api/upd/check`, сервер передаёт вызов оболочке (`hooks.updCheck`), та спрашивает GitHub, сама качает новую версию и предлагает перезапуститься.
- `server.js` — локальный сервер для окна: те же адреса `/api/*` и токен `X-BM-Token`, что у программы BazisReborn (`app/go/server.go`), в том числе проект одним файлом (zip без сжатия внутри `.bmk`). Ядро C++ BazisReborn не подключено — считает JS.
- `web/` — окно и расчётное ядро (копия `app/web` BazisReborn 2.2.1). Правки STHGroup помечены комментарием «STHGroup».
- `bazis/STHGroup_Export.js` — скрипт выгрузки модели из БАЗИСа в проект `.bmk` (на основе скрипта BazisReborn 1.11). Окно выгрузки (mshta, вариант «C»): слева сводка модели и ход выгрузки, справа данные заказа — заказчик, номер заказа, изделие, комментарий (в проект: `model.customer`, `model.orderNo`, `model.title`, `model.note`). Закрыли окно — выгрузка отменена; нет mshta — данные из модели, программа открывается сама. Ставится из программы: «Файл → Скрипт для БАЗИСа…» (папка STHGroup в папке скриптов БАЗИСа, скрипт латиницей + значок `STHGroup_Export.bmp`); при каждом запуске программа обновляет его и пишет свой путь в `%APPDATA%\STHGroup Cutting\exe.txt`.
- Тема одна — «STHGroup»: графит и оранжевый (`html[data-skin="sth"]` в `web/app.css`). Заставка BazisReborn отключена; своя — `web/ui/sth_splash.js` (вариант «Спокойная»: знак с тёплым свечением, буквы названия по очереди, версия программы; ~2 с, щелчок или клавиша — пропустить; не показывается при выключенных анимациях).
- База материалов — окно BazisReborn (`web/matbase.html`). STHGroup добавляет (`web/ui/sth_shop.js`, разбор страницы — `web/core/linkparse.js`): в карточке на вкладке «Поставщик» у «Ссылки на товар» — «Заполнить по ссылке» (цена, наличие, артикул, название, размеры, поставщик, остаток и характеристики в примечание) и «Войти на сайт»; «Инструменты → Обновить цены по ссылкам…». Групповое редактирование (`web/ui/sth_mb.js`) — как в БАЗИСе: та же карточка «Материал» с пустыми полями, меняется только заполненное, галочки в три положения, классы «Добавлять / Заменить»; Ctrl+A — выделить все.
- «Нет в базе» (`web/ui/sth.js`): после открытия проекта — плиты, кромка, погонные, фурнитура и профили сметы, которых нет в базе, списком с галочками; правятся название и артикул, группа — своя для вида (или новая «Из моделей: …»); записываются с единицей, толщиной и форматом листа из проекта. Окно — один раз на набор недостающего, снова — кнопкой «Нет в базе: N» над сметой.
- «Сопоставить с базой» (`web/ui/sth.js`): кнопка у каждой строки сметы (плита, кромка, погонный, фурнитура, профиль): ✓ и название материала базы, если найден, иначе «Сопоставить с базой» — открывается окно «База материалов» в режиме выбора (`web/ui/sth_mb.js`): дерево групп, таблица, поиск, полоса «Выбрать / Отмена / Отвязать», двойной щелчок — выбрать. Связь «наименование из модели → материал базы» хранится в базе (`links`) и действует во всех проектах; связь главнее поиска по наименованию и артикулу.
- «Заменить…» (`web/ui/sth_replace.js`, с 0.9.15): у любой строки материала сметы можно выбрать другой товар из базы — в смету, итоги, КП, счёт и заказ попадут его название, артикул, количество/единица, цена, поставщик и фото. В окне замены — количество модели или по правилам базы (округление и целые упаковки) и галочка «Запомнить для всех проектов». «заменено ↶» возвращает строку модели только здесь или убирает общую замену. Это подмена позиции, а не сопоставление для цены.
- Окно «Поставщик» у строки сметы (`web/ui/sth_sup.js`): материал базы строки («✓», «Сопоставить…» или «Записать в базу»), ссылка с «Заполнить по ссылке» и «Войти на сайт», цена, поставщик, артикул, фото — всё пишется в базу материалов; над сметой — «Обновить цены по ссылкам» (фото с сайта — `/api/shop/image` в `main.js`).
- Заказы и клиенты (`web/core/sth_order.js` — книга и расчёт, `web/ui/sth_orders.js` — разделы, справочник, КП и счёт): разделы «Заказы» (список | заказ: Расчёт / Изделия / Оплаты | итог, аванс, условия) и «Клиенты». Книга — файл «STHGroup — заказы.json» в общей папке (по умолчанию — папка базы материалов). Заказ — несколько изделий (.bmk); открытый проект сам попадает в заказ по номеру из окна выгрузки или по файлу, иначе — новый заказ с клиентом из окна. Расчёт как у фабрики: обработка листового материала за лист по виду работы (вид — по словам в названии материала), мелкие детали (длина или ширина меньше порога: кромление, присадка — за деталь), услуги с галочками (за заказ, лист, изделие, деталь, % от суммы), скидка за комплекс (% от услуг), материалы и фурнитура по смете с наценкой, аванс (% услуг + % материалов), доплата, оплаты, долг. Модель изделия копируется в папку заказа («Заказы\\<номер клиент>» в папке заказов), щелчок по заказу открывает его модели. Вид работы за лист — по словам в названии материала и толщине; разделы «Дополнительные работы», «Фасады МДФ с эмалью», «Фрезеровка без эмали» — количество вписывается в заказе; «Срочно» — +30% к услугам. Работы (распил, кромка, пазы и др.) в смете не показываются — они в заказе. КП (макет «B») и счёт — предпросмотр в окне программы, затем PDF. «Своя строка» в услугах — название, единица, цена, количество правятся в строке.

Полное описание для продолжения работы — `ПОЛНОЕ ОПИСАНИЕ.md`, правила работы с автором — `AGENTS.md`, картинки выбранных вариантов оформления — `docs/design/`.

## Проверки
```bash
npm test          # заказы и расчёт КП (t_orders), образцы моделей, выгрузка с окном данных заказа (t_export), моделей (имитация БАЗИСа), раскрой, проект, смета, база материалов, замена позиций (t_replace), проект одним файлом, сервер окна, заставка (t_splash)
node server.js <папка данных> [проект.bmk] [порт]   # окно без Electron — для проверок в Chromium (Playwright)
```
`t_est.js` нужны `pdfinfo`, `pdftotext`, `unzip` — на сборке GitHub (Windows) идёт `npm run test:ci` без него.

## Выпуск
Поднять `version` в `package.json` и отправить в `main`: GitHub Actions соберёт установщик и выпустит его, установленные программы обновятся сами.
