# STHGroup Viewer 0.1 — для заказчиков

Отдельный демонстрационный сайт. Компоновка Б: крупная 3D-модель, вкладки сверху, состав справа. На телефоне состав располагается под моделью. Liquid Glass, русский интерфейс. Electron-приложение не изменено.

## Запуск

Нужен Node.js 20 или новее. Из каталога viewer выполнить npm start.
Адрес: http://127.0.0.1:47920. Порт меняется переменной PORT. Нет внешних CDN, зависимостей для установки и передачи данных сторонним сервисам. Three.js r160 взят из приложения, MIT-лицензия сохранена.

## Что работает

- Процедурная 3D-модель кухни: мышь, колесо, сенсорные жесты, клавиатура. Выбор группы с подсветкой, скрытие фасадов, исходный ракурс.
- Сворачиваемый состав и материалы, отдельная вкладка изделия.
- Вкладка статуса заказа с текущим этапом.
- Навигация по URL-фрагменту и клавиатурой, сообщение при недоступном WebGL.
- Клиентский пакет не содержит внутренних смет, цен, карт раскроя или склада.

## Ограничения

Все данные демонстрационные, модель создана кодом как пример кухни. Пока нет импорта реальных .bmk/.glb, связи с приложением, хранения рабочих заказов, авторизации и индивидуальных ссылок со сроком действия. При импорте учитывать glTF 1.0 из БАЗИСа. До реализации серверных разрешений нельзя размещать рабочие модели или персональные данные в public.
Демонстрационный сайт можно разместить на сервере отдельно. Это не означает, что он уже подключён к рабочим заказам.

## Ubuntu / Debian

Приложение слушает только 127.0.0.1. Внешний доступ предоставляет Nginx. Образцы: deploy/sthgroup-viewer.service и deploy/nginx.conf.

1. Установить Node.js 20+ и Nginx, скопировать содержимое viewer/ в /opt/sthgroup-viewer.
2. Создать системного пользователя sthviewer, дать ему чтение файлов сайта.
3. Установить service-файл в /etc/systemd/system/sthgroup-viewer.service, затем systemctl daemon-reload и systemctl enable --now sthgroup-viewer.
4. Заменить viewer.example.com в конфигурации Nginx на настоящий домен, установить конфигурацию и выполнить nginx -t перед перезагрузкой.
5. Настроить HTTPS-сертификат для настоящего домена и проверить сайт на телефоне.

Секреты, серверные ключи и рабочие модели в GitHub не добавлять. Подключение к серверу, DNS и сертификат ещё не выполнялись.

## Проверки

npm test — тест сервера без сторонних библиотек.
node test/browser.cjs — браузерная проверка при запущенном npm start и установленном Playwright с Edge.
STH_PLAYWRIGHT — путь к модулю Playwright, STH_VIEWER_PREVIEW — каталог снимков вне исходников.
Проверено в изолированном Edge при 1600/390/360 пикселях. Не проверено: физический телефон, реальный Linux-сервер, модели из БАЗИСа.

Текст для тестирования: «Поверните и приблизьте модель, выберите группу, скройте фасады. Проверьте вкладки изделия и статуса. На телефоне состав должен идти под моделью, кнопки и вкладки не должны перекрываться».

Проверки основного приложения: test:ci пройдены. Полный npm test останавливается на прежнем PDF-тесте: отсутствует /opt/pw-browsers/chromium. Это ограничение окружения, файлы приложения не менялись.
